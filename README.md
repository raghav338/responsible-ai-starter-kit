# Responsible AI Starter Kit

Dual-track project: NIST-aligned AI risk register + LLM red-team harness.

## Day 1 Notes

- NIST AI RMF is a framework for managing risks associated with AI systems.
- The four core AI RMF functions are Govern, Map, Measure, and Manage.
- Govern establishes organizational policies, responsibilities, and risk-management practices.
- Map identifies the context, potential impacts, and risks associated with an AI system.
- Measure and Manage involve evaluating risks and taking appropriate actions to address them.

## OWASP LLM Top 10

- OWASP LLM Top 10 is a security-focused guide for risks affecting applications built with Large Language Models.
- Prompt injection is a major risk involving manipulation of an LLM through crafted inputs.
- Sensitive information disclosure concerns unintended exposure of confidential information.
- The list helps developers identify common security weaknesses in LLM applications.
- OWASP guidance can be used as a starting point for testing and improving LLM application security.
